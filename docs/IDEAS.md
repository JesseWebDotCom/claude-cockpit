# Ideas

Not built. Each one is a request from the owner, kept here until it is scheduled.

## Animated characters in the summary tiles

The four tiles under the goal card (Running, Needs you, To go, Done) each get a small animated character.
A tile whose count is 0 shows its character asleep; a tile with a count above 0 shows it active (the Running
character runs, and so on for the others). The character reads the same count the tile already shows.

## Dancing character when the plan is done

When every step of the plan is done, a character dances above the progress bar in the goal card, in the space
under the "synced" line. It goes away when a new step opens.

## Goal card stays fixed at the top

On the plan page, the goal card stays pinned at the top and everything else scrolls underneath it.
